# Identity and modules in Synesism: source-grounded formalization note

**Status:** research interpretation, not a canon amendment. This note supersedes the earlier observer-equivalence-only reading.

## 1. What the available sources support

The connected workspace contains older draft chapters (2015–2016) and topic notes last edited 2025-08-07. The exact current P1/P8 source referenced in earlier discussions was not found in this workspace, so earlier paraphrases must not be treated as canonical.

The available sources support the following distinctions:

- **Semonic equivalence is not structural identity.** *2. Definitions and Premises* and *5. Sema* explicitly distinguish equal semonic value from equality of configurations, mappings, and properties.
- **Signatures individuate sema.** The older definitions describe a signature as a pathway from a synod to a being in the Worldtree and say signatures distinguish sema. The uniqueness conditions need formal reconciliation with the source's semilattice/cycle descriptions.
- **System identity is anchored by the synod.** *7. Systems* calls the synod the system's invariant/identity element and requires semonic value preservation under coherent transformations.
- **Syneces are relations.** *6. Syneces* treats them as conversion factors/morphisms between entities and describes logic as semonic-preserving entailment.
- **Modules are partial reality-slices.** The 2025 *Module* note describes them as contingent access to portions of reality generated by interactions among entities with different signatures and fitness functions. They are not merely arbitrary observer opinions.
- **Value has two aspects.** The 2025 *Two notions of value* note distinguishes internal semonic content from external/contextual fitness. The 2025 *On identity* note questions numerical identity for differentiated beings and emphasizes relational individuation and practical/moral criteria. This creates a tension with the older chapter's synod-as-system-identity language; these notions must remain distinct pending reconciliation.
- **Markov blankets are a proposed identity analogy.** The 2025 “Sema are types, entities are sets, systems are classes” note suggests identity as Markov blankets operating over regularities at multiple levels. This is not yet a formal definition of synod or module.

See `research/SYNESISM_IDENTITY_MODULE_RECONCILIATION.md` for the detailed source map and `research/SYNESISM_MODULE_SEMANTICS_DESIGN.md` for a candidate formal signature.

## 2. The central distinction

Do not infer:

    equal semonic value  =>  structural identity

The binary source example says one zeroth-order semon and two first-order sema can have the same aggregate value while remaining structurally different.

The first dyadic model is now formalized in `proofs/lean/SynesismConservation.lean`:
- each first-order offspring has half the parent's value;
- two first-order offspring have the same aggregate value as the parent;
- binary partition preserves value while changing order/configuration;
- a system state can evolve while preserving its synod anchor and semonic invariant.

This is a toy formalization of the binary example, not a general theory of molarity or the full Worldtree.

## 3. Four distinct layers

1. **System identity/persistence:** track the synod and semonic invariant across changes of configuration.
2. **Structural individuality:** track signature, order, mappings, and scheme.
3. **Module-relative access:** track the interaction, target system, time, fitness function, accessible slice, and validity domain.
4. **Operational boundary:** a Markov blanket may characterize conditional-independence boundaries in a probabilistic model, but it is not automatically the same thing as a module or synod.

A module is therefore not simply an observer-indexed equivalence class. Nor does local observational equivalence establish system identity.

## 4. What the current Semplex formalization does

- `Distinction.lean` formalizes quotient/query preservation, operation congruence, identity substitution, a first-order satisfaction fragment, and resource-sensitive contraction.
- `SmallFibration.lean` is a small standard fibration with discrete Boolean fibers.
- `ModuleDescent.lean` proves a finite two-module matching/gluing result.
- `SynesismConservation.lean` formalizes the dyadic value-preserving partition example.

All four Lean modules compile and pass the axiom audit under Lean 4.12.0. The Python demonstrator passes 9/9 tests. These results are not yet a formalization of the Synesism module ontology. In particular, the current fibration/gluing examples do not yet include fitness functions, partial reality-slices, reality-share accounting, or Markov blankets.

## 5. Open questions

1. What is the exact current P1/P8 wording and source? The earlier headline “identical signature and semonic value imply identity” remains unverified against the connected workspace.
2. Is the synod a distinguished object, limit/colimit, invariant, or another categorical structure?
3. Is a signature a unique path, path-equivalence class, or another structural locator? How does uniqueness coexist with cycles?
4. What algebraic structure does relative molarity have? Is it a scalar, valuation, or richer invariant?
5. What exactly is the module's reality-share, and how are overlaps counted under unitarity?
6. How do internal semonic value and external fitness interact?
7. Does a Markov blanket characterize the identity boundary, module accessibility, or a relation between them?
8. Which syneces are full (value-preserving) and which are quasi (value-changing), and how do they compose?

## 6. Next formalization tests

1. Define relative molarity and its algebraic laws beyond the dyadic case.
2. Formalize synod-preserving system transformations and the Principle of Coherence.
3. Define modules from agent/target/time/fitness data, with explicit validity domains.
4. Choose a mathematically precise unitarity accounting model for allocated shares versus overlapping measurable subsets.
5. Construct a non-discrete indexed category/fibration of modules only after the base category and reindexing maps are source-grounded.
6. Prove a descent theorem for a specified module cover, if the source semantics supplies the required overlaps.
7. Relate the module boundary to Markov blankets through a probabilistic model, not a verbal analogy.

No canon amendment is implied by these experiments.
