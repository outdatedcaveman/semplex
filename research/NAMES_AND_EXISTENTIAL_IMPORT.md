# Names, assignments, and existential import in first-order logic

**Status:** mathematical clarification for Spike 17; standard model-theoretic results, not a novelty claim.

## 1. Three things that must not be conflated

1. **Variable**: a syntactic variable whose value is supplied by an assignment s : Var → D.
2. **Constant symbol/name**: a nullary function symbol c in the language signature, interpreted in a structure M by a designated element c^M ∈ D.
3. **Eigenparameter/fresh name in a derivation**: a proof-theoretic parameter chosen fresh under a side condition. Semantically it is interpreted by an arbitrary domain element; it is not a canonical object or a new ontological entity.

The Tarski slide concerns assignments to free variables. It is not a theorem about constant symbols directly.

## 2. Why a constant has inferential consequences

In standard first-order semantics, structures have nonempty domains and each constant symbol denotes an element. Therefore:

    M ⊨ ∃x (x = c)

because c^M is a witness. In a natural-deduction proof, this follows from reflexivity c=c and existential introduction.

The inference is not generated by the bare written name. It depends on three coordinated choices:
- the signature contains a constant symbol c;
- the semantics interprets c as an element of a nonempty domain;
- the proof system has equality reflexivity and existential introduction.

A fresh parameter used to instantiate a universal formula is interpreted by an arbitrary domain element. It supplies a witness for existential introduction, but its freshness/eigenvariable condition must be respected when discharging assumptions or generalizing.

## 3. Existential import and empty domains

For standard nonempty-domain first-order semantics:

    ∀x φ(x) ⊨ ∃x φ(x)

Choose any d in the nonempty domain. The universal statement gives φ(d), hence d witnesses the existential.

If empty domains are allowed, the implication fails: ∀x φ(x) is vacuously true over the empty domain, while ∃x φ(x) is false. Empty-domain semantics is a legitimate alternative studied in logic, but it is not the standard semantics assumed by ordinary first-order logic courses and proof systems unless explicitly stated.

Thus the slide's derivation encodes a domain-nonemptiness convention. It does not show that universal quantification intrinsically contains an existential witness in every semantics.

## 4. The Tarski satisfaction-invariance slide

For a formula φ, satisfaction M,s ⊨ φ depends only on s restricted to the free variables FV(φ):

    s|FV(φ) = s'|FV(φ)
      implies
    (M,s ⊨ φ iff M,s' ⊨ φ).

This is a semantic invariance theorem. It says that assignment coordinates not read by φ can be forgotten for evaluating φ. For a sentence (a formula with no free variables), satisfaction is independent of the assignment.

It is therefore a direct instance of quotienting by a formula-indexed kernel relation. The quotient changes with φ: an assignment coordinate irrelevant to φ may be relevant to ψ.

## 5. Names, co-reference, and substitution

Two constant symbols c and d may denote the same element in a particular structure, or different elements. The strings c and d do not determine co-reference by themselves.

With logical equality, if c=d holds in a structure, then any formula context in which equality is substitutive preserves truth under replacing c by d. This is congruence of equality with respect to the language's interpreted operations and predicates.

But this must not be generalized blindly to opaque or intensional contexts. In modal, epistemic, quotation, hyperintensional, or provenance-sensitive settings, co-reference at the object-language level may not license replacement inside every context. One must specify the semantics and congruence conditions.

This is precisely the distinction calculus's operation-preservation obligation: preserving current denotations or observations is insufficient unless the equivalence is respected by every protected context/operation.

## 6. Consequence for the four-system comparison

- Classical FOL: names denote because the signature interpretation says so; equality licenses substitution; standard nonempty domains support existential import.
- Linear logic: a name or formula may have the same content while occurrences remain separate resources; co-reference does not authorize contraction.
- Dependent type theory: variables are bound in contexts; substitution is reindexing, while identity proofs support transport. A name is not a substitute for a path.
- Context-/module-indexed semantics: reference is interpreted relative to a module's interface and validity domain. Cross-module substitution requires a compatibility/descent theorem.

## 7. Research implication

The correct target is not “eliminate names” in isolation. It is to make explicit the semantic and inferential commitments attached to:
- signature extensions;
- denotation maps;
- fresh parameters and witness introduction;
- equality/congruence;
- free-variable support;
- context-sensitive substitution.

The Lean first-order fragment now includes an explicit existential formula constructor, existential introduction, semantic soundness of universal introduction under the fresh-variable condition, and semantic soundness of existential elimination when the eigenvariable is absent from the persistent context and conclusion. The proof uses the free-variable satisfaction theorem to show that changing the eigenvariable cannot affect those protected formulas. This is still a small language (equality, unary predicates, falsity, implication, universal and existential quantification), not full first-order logic or a complete natural-deduction calculus.

A fresh eigenvariable is not a constant denoting a pre-existing named object. Its admissibility comes from a syntactic non-occurrence condition that guarantees the conclusion/context are independent of its assigned value.
