# Candidate formal semantics for Synesism modules

**Status:** research design only; no axiom or formal definition added to Synesism canon.  
**Depends on:** `SYNESISM_IDENTITY_MODULE_RECONCILIATION.md`, Spike 17's verified generic fibration and finite gluing fragments.

## 1. Source constraints

The current canon defines a module as a partial, perspectival reality-slice accessed by a contingent being at a given time. The lexicon sharpens its generation condition: it is produced by interactions among multiple entities with differing signatures and therefore differing fitness functions. Modules are real; illusion is a module misapplied outside its validity domain. Their relevance/truthfulness hierarchy is ordered by **many partial orders, not one**. P8 states that the sum-total of reality shared across all entities equals one at all times (module-level unitarity). These are the constraints the model must preserve.

The two-notions-of-value note distinguishes internal semonic content from external/contextual fitness. The Systems chapter anchors system identity/invariance in its synod and requires coherent transformations to preserve semonic value. The current P1 canon distinguishes true identity from phenomenological identity; the short 2025 *On identity* note separately asks what practical criterion individuates one thing from another and links that question to accountability. It does not itself settle the metaphysics of identity. The older Systems chapter calls the synod a system's invariant/identity element, so the formal model must treat it as a system anchor without automatically equating it with ordinary numerical identity.

A formal module must therefore not be identified with:
- the entity itself;
- its synod;
- its complete Worldtree;
- an arbitrary observer label;
- an equivalence class defined only by current observations.

## 2. Candidate data model

A module candidate is indexed by the full interaction context, not by a single observer/agent alone:

    InteractionContext =
      (participants,
       target-system,
       time/state,
       signatures of participants,
       fitness-functions of participants)

    ModuleIndex = InteractionContext

A local module should carry:

    Module =
      (index,
       accessible-reality-slice,
       access-map,
       validity-domain,
       contextual-fitness-profile,
       relevance/truthfulness-order-family,
       module-reality-share)

The order family is a family of partial orders indexed by an as-yet-unspecified context set; do not collapse it to one total order or one scalar fitness score.

The separate “On the multitude of modules” note adds an extensionality constraint inspired by clustering: a well-defined cluster contains **all and only** elements to which a given function F applies. Treat this as a candidate exact-carrier condition, not yet a complete definition of modulehood. A candidate representation is:

    applicability : InteractionContext -> Entity -> Prop
    carrier(M) = { x | applicability(M.index, x) }

The note also says there are many more modules than synods. Therefore module-to-synod correspondence must not be assumed one-to-one. The Module note explicitly warns that structural features such as numbers, although emergent, are not reducible to modules; the model must not equate “partial” with “merely subjective” or classify every emergent feature as a module.

Possible typed functions:

    molarity : Entity -> SemonicValue
    contextualFitness : Agent -> Entity -> FitnessValue
    signature : Entity -> Signature
    synod : System -> Synod
    access : ModuleIndex -> GlobalState -> LocalState
    valid : ModuleIndex -> GlobalState -> Prop
    moduleRealityShare : Module -> RealityShare
    relevanceOrders : ModuleContext -> Family (PartialOrder Module)

These are signatures for a candidate model, not established definitions. In particular, the codomains and algebraic structure of SemonicValue, FitnessValue, RealityShare, and the index family for the partial orders remain open. The first argument of contextualFitness is an agent/participant whose fitness function is being evaluated against the second entity; it is not necessarily a single privileged observer.

## 3. Three layers that must remain distinct

### 3.1 Ontological system

A system has a synod anchor, a semonic invariant, a configuration/scheme, signatures, and syneces. Its state can change while the synod and total semonic value remain invariant.

### 3.2 Module / partial reality-slice

A module is generated by an interaction and a fitness/access regime. It is a partial view with a validity domain. Different combinations of interacting entities, signatures, and fitness functions can induce different modules over the same target system.

### 3.3 Markov blanket / operational boundary

The 2025 topic note suggests identity as Markov blankets operating over regularities at multiple levels. A candidate probabilistic representation has internal states I, external states E, and blanket states B satisfying:

    I ⟂ E | B

The Markov blanket is a boundary condition in a probabilistic model. It should not be equated automatically with the synod or with the module itself. A module may be the accessible slice induced by an interaction across such a boundary.

## 4. Fibration hypothesis

A base category could represent changes in interaction context:
- restricting an agent's access;
- refining or coarsening a fitness criterion;
- changing time/state;
- moving between overlapping module contexts.

The fiber over a context would contain its local module descriptions, local system states, and admissible local transformations.

Reindexing would restrict a local description to a weaker/coarser context. Cartesian arrows would express the universal way to transport a local description along a context change.

This gives a plausible use for the verified small fibration, but a genuine Synesism construction requires:
1. a principled base category of module contexts;
2. explicit local state spaces;
3. reindexing maps derived from the source's interaction/fitness semantics;
4. composition and identity laws;
5. an account of validity domains;
6. overlap maps and a specified compatibility relation.

Until these are supplied, the existing `SmallFibration.lean` is only a generic proof-of-concept.

## 5. Unitarity: two possible mathematical readings

P8's module-level unitarity says the sum-total of reality shared across all entities equals one at all times. The canon does not yet specify a measure or how overlaps are counted. Keep this quantity distinct from **molarity**: the lexicon separately defines molarity/semonic value as conserved across partition and conjoinment and summing to one per closed system. No source currently establishes that module reality-share and molarity are the same valuation. Two candidate formalizations of P8 must be kept separate.

### A. Allocated-share semantics

Each agent/module receives an allocated share (w_i), with:

    0 ≤ w_i ≤ 1
    Σᵢ wᵢ = 1

Shared content is represented by fractional allocation, so the same content is not independently counted in full by multiple observers.

### B. Overlap-measure semantics

Each module is a measurable subset (M_i) of a common reality space Ω, with:

    μ(⋃ᵢ Mᵢ) = 1

Overlaps are represented explicitly by intersections and a measure algebra. In this interpretation, Σᵢ μ(Mᵢ) need not equal one unless the cover is disjoint or a separate allocation convention is supplied.

These are not equivalent in general. The source's discussion of overlapping perceptions may support either a shared allocation or a measure on overlaps. It does not yet decide between them. Neither option may be identified with molarity without a separate bridge theorem.

A proof must not assume additivity across overlapping modules without resolving this.

## 6. Descent hypothesis

For a family of modules covering a target system, local descriptions might glue when:
- their restrictions agree on every overlap;
- their validity domains are compatible;
- their synod anchors agree;
- their semonic invariants agree;
- their local syneces compose consistently;
- their reality-share accounting satisfies the chosen unitarity semantics.

The generic finite gluing theorem in `ModuleDescent.lean` proves only the elementary product case. A Synesism descent theorem would require the full conditions above and a proof of existence and uniqueness of a global system description.

## 7. Open mathematical questions

1. Is the synod an object in a category of sema, a distinguished limit/colimit, or a separate invariant?
2. Is a signature literally a path in a graph/semilattice, or a path-equivalence class? How is uniqueness reconciled with cycles in the Worldtree?
3. Is semonic value a scalar, a relative valuation, a conserved measure, or a richer invariant?
4. Is contextual fitness ordered, probabilistic, or merely a comparison relation?
5. Is a module an object/subobject, a partial section, an accessible subspace, or a structure generated by an interaction?
6. Is the reality-share unitarity principle about allocated shares or the measure of overlapping subsets?
7. Does the Markov blanket characterize identity, module access, or a relation between them?
8. Which transformations are full logics (semonic-preserving) and which are quasilogics (value-changing)? How does this classification compose?

## 8. Implementation sequence

1. Formalize the relative dyadic molarity example, prove the value relation is an equivalence, and show structural order/multiplicity do not descend through its quotient. **Verified in `SynesismConservation.lean`; general relative molarity remains open.**
2. Define a typed `SystemState` with synod, configuration, signatures, and syneces; prove the Principle of Coherence for a nontrivial family of transformations.
3. Choose and formalize the contextual-fitness type.
4. Define module indices and local state spaces from agent/target/time/fitness data.
5. Choose an explicit unitarity semantics and prove its accounting laws.
6. Build a non-discrete indexed category/fibration of modules.
7. State and prove a descent theorem for a specified module cover.
8. Compare the resulting construction with standard sheaf theory, Markov blankets, categorical semantics, and active inference before claiming novelty.

No step should be promoted to Synesism canon merely because it has a convenient mathematical representation.
